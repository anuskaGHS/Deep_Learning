# Deep Learning: Skill Development Projects

> **Academic notice:** This repository is created **only for university submission purposes**. It holds my Deep Learning skill-development projects for the BCA (AI & ML) programme at Alliance University, Bangalore (Semester V). It is not a standalone project. Please do not copy this work for your own submissions.

## What is in this repository

Twelve numbered projects. Projects 1 to 4 are a presentation, a worked example and two written reports. Projects 5 to 12 are Jupyter notebooks that build the core ideas of neural networks step by step.

| # | Project | Format |
|---|---|---|
| 1 | AI in Our Daily Life | Presentation (`.pptx`) |
| 2 | Neural Network Forward Propagation Using Mathematical Calculations (single hidden layer, Iris dataset) | Handwritten PDF |
| 3 | Comparison of Deep Learning Architectures | Report (`.docx`) |
| 4 | Ethical Considerations in Deep Learning | Report (`.docx`) |
| 5 | Activation Functions Using Python | Notebook |
| 6 | Simple Neural Network Forward Propagation (Iris) | Notebook |
| 7 | Loss Functions in Neural Networks | Notebook |
| 8 | Gradient Descent Implementation | Notebook |
| 9 | Optimizer Comparison Using a Neural Network | Notebook |
| 10 | Overfitting and Underfitting Analysis | Notebook |
| 11 | Handwritten Digit Classification Using CNN (MNIST) | Notebook |
| 12 | Understanding Convolution and Pooling | Notebook |

## Tools and libraries

Python, NumPy, scikit-learn, TensorFlow, SciPy, Matplotlib, Seaborn, Jupyter Notebook.

## How to open the notebooks

1. Clone the repository:
   ```bash
   git clone https://github.com/anuskaGHS/Deep_Learning.git
   ```
2. Open any `DL_ProjectN.ipynb` file in Jupyter Notebook or Google Colab.
3. Run the cells from top to bottom. Datasets such as Iris and MNIST are loaded through the libraries.
